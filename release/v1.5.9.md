# 1.5.9 — current-post capture fix

## Cause

The bookmark handler waited 200 ms, then selected the first `div[data-pressable-container="true"]` in the entire document. Threads retains hidden feed/detail trees during SPA navigation. A live logged-in inspection on 2026-10-20 confirmed that the first container belonged to the hidden feed, while the visible detail post occurred later (including a hidden duplicate of the current post). The handler neither checked visibility nor matched the current permalink.

The like handler was already scoped to the clicked button, but resolved its post and content after a delay. Navigation, a detached button, or DOM reuse could therefore change the saved target. Thread/comment collection also scanned the entire document.

## Changes

- Resolve bookmark targets by their own timestamp permalink and current post ID; exclude hidden, nested quote and ambiguous matches.
- Capture the More menu's post context so a reply's menu saves that reply; reject stale contexts after navigation.
- Extract bookmark content synchronously before the menu closes or navigation changes the DOM.
- Capture like content at click time; verify the same connected, visible post and page after the active-state update. Ignore unlike and unchanged Like labels.
- Scope related posts to the current region/dialog/main and filter hidden trees and nested posts.
- Deduplicate by permalink ID rather than author + timestamp.
- Display a localized retry message if the current bookmark target cannot be identified.
- No new runtime dependencies or permissions. Feed bookmarks remain unsupported; feed likes remain supported.

## Validation

- `npm ci --ignore-scripts && npm test`: 24 DOM integration tests using the unmodified production content script, mocked Chrome messaging, layout visibility and timers. Verify the emitted save payload (no real Obsidian writes).
- Cases cover hidden retained pages, hidden duplicates, visible unrelated predecessors, missing/ambiguous targets, quotes, article wrappers, media/query URLs, stale menus, synchronous navigation, reply menus, English/Korean/legacy like icons, unlike, unchanged icons, navigation, detached/recycled DOM, snapshots, deduplication and related-post scope.
- Against the original 1.5.8 script, the initial 21-test suite had 16 failures; the fixed script passed all 24 final tests.
- `node --check content/content.js`, `git diff --check`, runtime-only ZIP packaging and `unzip -t`: passed.
- Live Threads DOM inspection verified retained hidden containers and current SVG title labels. Actual installed-extension click → Obsidian persistence was not exercised for 1.5.9; the integration tests intercept the save boundary.
